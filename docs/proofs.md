# Finite semantics, certificate theorems, and hardness boundaries

This document gives the complete handwritten mathematical argument implemented by the artifact. It is not a proof-assistant development. The executable checks in `results/` validate finite instances and malformed-certificate rejection; they do not replace the quantified proofs below. All statements are restricted to the declared finite, acyclic, immutable-input model.

## 1. Alphabets, worlds, source workflows, and observations

Let `K` be a finite ordered set of Boolean input keys and `R` a finite ordered set of observable result labels. A **world** is a total function `rho : K -> {0,1}`. Repeated reads of the same key in one run return the same value. The two controllers compared by the relational semantics use one common world; neither chronological response matching nor independent worlds is the intended contract.

A source workflow is generated by

```
W ::= fail | return(r) | split(W,W) | test(k,W,W).
```

For a fixed world, its terminal denotation is

```
D_rho(fail)       = empty
D_rho(return(r))  = {r}
D_rho(split(U,V)) = D_rho(U) union D_rho(V)
D_rho(test(k,U,V))= D_rho(U) if rho(k)=0, otherwise D_rho(V).
```

A search configuration is an ordered frontier of pending source trees and a cumulative output set. One expansion removes one policy-selected pending tree. A failure adds nothing, a return inserts its result, a split adds both children, and a test adds the single child selected by the world. FIFO, LIFO, query-first, and emit-first never prune; beam-one and first-result deliberately prune.

### Lemma 1.1 (decreasing mass)

Let the syntax size count one for every constructor and define the frontier mass as the sum of the sizes of its pending trees. Every expansion decreases mass by at least one. Therefore every source run terminates after at most the size of its initial tree expansions.

**Proof.** Removing a failure or return removes one unit. Replacing a split by both children removes exactly its root. Replacing a test by one child removes its root and the entire unselected subtree. Pruning removes still more mass. The mass is a nonnegative integer. QED.

### Theorem 1.2 (terminal agreement of non-pruning policies)

For any world, every policy that expands exactly one pending task and never discards another pending task terminates with output `D_rho(W)`.

**Proof.** Maintain

```
A union (union of D_rho(U) over U in frontier) = D_rho(W),
```

where `A` is the cumulative output. Each constructor preserves the equality by the defining equations above. By Lemma 1.1 the frontier becomes empty, leaving `A = D_rho(W)`. No fairness premise is needed because the tree and every run are finite. QED.

This theorem is intentionally only a terminal null result. Two non-pruning policies may discover the same result at different expansion budgets.

## 2. Explicit acyclic controllers and source compilation

An explicit controller has a finite node set with a distinguished entry. Each node is one of:

* `halt`;
* `step(next)`;
* `emit(result,next)`; or
* `read(key,zero,one)`.

Every non-halt edge points strictly forward in a supplied topological order. A halt pads itself without consuming additional observable behavior. Every other instruction consumes one tick; an emit adds one label to the cumulative set. For controller `C`, world `rho`, and budget `b`, write `O_C(rho,b)` for the cumulative output after `b` ticks, with halt padding. A complete horizon is `|V_C|`, and for a pair we use `H=max(|V_L|,|V_R|)`.

Two controllers are **budgeted common-world equivalent** when

```
for every world rho and every b in {0,...,H}, O_L(rho,b)=O_R(rho,b).
```

For an inequivalent pair, the globally least separating budget is

```
b* = min { b : some rho has O_L(rho,b) != O_R(rho,b) }.
```

### Source compiler

For a fixed source workflow and a deterministic frontier policy, create one controller node for each syntactically reachable ordered frontier. The empty frontier is halt. Expanding a failure or split yields a `step`; expanding a return yields an `emit`; expanding a test yields a `read` whose two successors are the frontiers produced by the two outcomes. The frontier update includes the policy's pruning rule. Ordering frontiers by decreasing mass makes every edge forward.

### Proposition 2.1 (compiler trace correspondence)

Direct source execution and execution of the compiled controller have identical cumulative observations at every budget under every world.

**Proof.** Relate a source configuration to the controller node denoting exactly its frontier, with identical cumulative output. The initial configurations are related. One source expansion and one controller instruction select the same pending tree and perform the same update. A test consults the same named key; a return adds the same result. The relation is preserved by one step and hence by induction on budget. When the frontier is empty, both sides remain halted. QED.

The proposition certifies only the included compiler. The explicit controller can be exponentially larger than a succinct source tree because different frontier orders and contents are separate control states.

## 3. Future-read sets and the reduced common-world product

For a controller node `p`, let `F_C(p)` be the set of keys read at `p` or at any node reachable from `p`. It is computed backwards:

* `F(halt)=empty`;
* `F(step(p'))=F(p')`;
* `F(emit(r,p'))=F(p')`;
* `F(read(k,p0,p1))={k} union F(p0) union F(p1)`.

For every edge `p -> p'`, `F(p')` is a subset of `F(p)`. Thus a key once absent from the future set can never be requested later on that continuation.

At paired controls `(p,q)`, define the live set

```
L(p,q) = F_L(p) union F_R(q).
```

A reduced product state is `(p,q,A,B,mu)`, where `A` and `B` are cumulative output sets and `mu` is a partial Boolean map whose domain is contained in `L(p,q)`. The root contains both entries, empty outputs, and empty memory. A state is **safe** when `A=B`.

At one synchronized tick, collect the at most two keys currently requested by the two instructions. Enumerate all assignments to requested keys absent from `mu`; a key requested by both sides receives one shared value. Execute both instructions, obtaining controls `(p',q')` and outputs `(A',B')`, then restrict the extended map to `L(p',q')`.

The full-history product is identical except that it retains every value exposed so far. Projection removes bindings not in the current live set.

### Lemma 3.1 (no resurrection)

If a binding is removed by projection at paired controls `(p,q)`, the key cannot be requested on any continuation from `(p,q)`.

**Proof.** A removed key is absent from both future-read sets by definition of `L`. Every continuation node is reachable from the current node, so the monotonicity of future-read sets keeps the key absent. QED.

### Lemma 3.2 (one-step lifting)

Let a full-history state project to a reduced state `s`. Every reduced successor of `s` is the projection of a full-history successor of the original full state.

**Proof.** Every key requested now belongs to the current live set. Therefore the full and reduced maps agree on every requested key that has previously been exposed. A key treated as fresh by the reduced step is not in the full history: if it were, it would be retained because it is currently live. Extend the full map with exactly the fresh assignments chosen by the reduced edge. Both sides take the same instruction branches and output actions. At the target, any previously exposed key that remains live was already live at the source and hence retained; restricting the extended full map therefore gives exactly the reduced target map. QED.

### Theorem 3.3 (exact common-world paths)

A finite path from the reduced root is realizable by one total common world, and every execution under one total common world projects to a reduced path.

**Proof.** For the forward direction, start with the empty full history and apply Lemma 3.2 edge by edge. The histories form a consistent extension chain. Complete the final finite partial map arbitrarily on keys never read. The resulting total world realizes the entire path. For the reverse direction, expose values from the fixed world whenever a key is first requested. Those values are among the compatible assignments enumerated by the reduced transition. Project after each tick. Induction yields the reduced path. QED.

The quantification in Lemma 3.2 is over every full history projecting to the source, not one selected representative. Consequently graph merging is sound: every suffix admitted from a merged reduced state can follow every represented prefix.

### Corollary 3.4 (bad-state characterization)

The controllers are inequivalent iff a reachable reduced state is unsafe. The shortest reduced path to an unsafe state has length `b*`.

**Proof.** By Theorem 3.3, every reachable reduced state is realized by a world at its path length, and every common-world observation pair occurs on a reduced path. Safety is exactly output equality. Minimizing path length therefore agrees with minimizing the separating budget over worlds. QED.

## 4. Positive and negative certificates

### 4.1 Positive closed-safe-set certificates

A positive certificate is a finite set `S` of well-formed reduced states such that:

1. the root belongs to `S`;
2. every state in `S` is safe; and
3. every compatible successor of every state in `S` also belongs to `S`.

The checker recomputes successors and future sets from the controllers.

### Theorem 4.1 (positive soundness and completeness)

The checker accepts a positive certificate only for equivalent pairs, and every equivalent finite pair has an accepted positive certificate.

**Proof.** Closure and root inclusion put every reachable reduced state in `S` by induction on path length; safety of members then excludes a reachable bad state. Corollary 3.4 gives equivalence. Conversely, for an equivalent pair take `S` to be all reachable reduced states. The set is finite, root-containing, and closed. Every member is safe by Corollary 3.4. QED.

Reachability of every supplied record need not be checked: adding an unreachable safe closed component cannot remove any obligation from the root component.

### 4.2 Globally least separating-budget certificates

A negative certificate contains a total world `rho`, a budget `t>=1`, and a finite safe set `S` with ranks `d:S->{0,...,t-1}`. It must satisfy:

1. the root is in `S` with rank zero;
2. whenever `d(s)<t-1`, every compatible successor `s'` is in `S` and `d(s')<=d(s)+1`;
3. replaying `rho` separates the controllers at budget `t`.

Rank-`t-1` records have no successor obligation because the certificate establishes safety only through budgets below `t`.

### Lemma 4.2 (ranked safe radius)

Every reduced state reachable in `j<t` steps belongs to `S` and has rank at most `j`.

**Proof.** The root establishes the claim for `j=0`. Suppose it holds at `j<t-1`. A state reachable in `j+1` steps has a predecessor reachable in `j`; that predecessor is in `S` with rank at most `j<t-1`. The universal successor condition therefore includes the target and assigns it rank at most `j+1`. Induction completes the proof. QED.

### Theorem 4.3 (negative soundness and completeness)

An accepted negative certificate proves `t=b*`. Every inequivalent finite pair admits an accepted certificate at `b*`.

**Proof.** Concrete replay supplies a separating world at `t`, so `b*<=t`. If a world separated at `j<t`, Theorem 3.3 would give a reachable unsafe reduced state at depth `j`, contradicting Lemma 4.2 and the safety of `S`. Hence `t<=b*`. For completeness, let `t=b*`, select a world separating at `t`, and put in `S` every reduced state whose shortest root distance is below `t`, ranked by that distance. Minimality of `t` makes every such state safe. Every successor of a state at distance below `t-1` has distance at most one more and is included. The replay condition holds by choice of world. QED.

A world and budget alone prove inequivalence but not global minimality. The ranked safe prefix supplies the missing universal obligation.

## 5. Discovery signatures and explicit state bounds

For result `r`, define its first-discovery time

```
tau_C(rho,r) = min { b : r in O_C(rho,b) },
```

using infinity if it is never emitted.

### Proposition 5.1 (discovery characterization)

Two controllers are budgeted common-world equivalent iff all their first-discovery times agree for every world and result.

**Proof.** Membership at budget `b` is equivalent to `tau<=b`. Conversely, unequal finite discovery times differ at the smaller time. QED.

Fix orders on keys and results. The function from a world to its vector of discovery times can be represented by a reduced ordered multi-terminal decision diagram: recurse on keys, use discovery vectors as leaves, and delete a test when both cofactors are identical. Standard ordered-decision reduction makes the representation canonical for the fixed order. The artifact's nested signature is only a small exact oracle, not an optimized decision-diagram implementation.

For node `p`, let `P_C(p)` be the union of keys read strictly before `p` on any syntactic entry-to-`p` path. Let `Ctr` be the set of syntactically reachable paired controls when read outcomes are unconstrained. Define

```
W(p,q) = (P_L(p) union P_R(q)) intersect L(p,q)
w = max |W(p,q)| over (p,q) in Ctr
r = |R|.
```

### Lemma 5.2 (binding support)

At any reachable reduced state with controls `(p,q)`, the remembered domain is contained in `W(p,q)`.

**Proof.** Every remembered key was read earlier on one of the actual control paths and therefore belongs to the corresponding may-past set. It is retained only if still live. QED.

### Theorem 5.3 (explicit reduced-state bound)

The number of reachable reduced states is at most

```
|Ctr| * 4^r * 3^w,
```

and every state has at most four compatible successors.

**Proof.** At fixed controls there are at most `2^r` output sets per side, hence `4^r` pairs. Each of at most `w` potentially remembered keys is absent, bound to zero, or bound to one, giving at most `3^w` maps. Sum over paired controls. At one tick, at most two distinct keys are requested, so at most four fresh assignments are enumerated. QED.

## 6. Decision complexity and the cost of stronger certificates

All complexity statements use explicit acyclic controllers of unbounded finite size and polynomial-time many-one reductions. They are separate from the artifact's fixed admission caps.

### Theorem 6.1 (equivalence is coNP-complete)

Budgeted common-world equivalence is coNP-complete, even with one result label.

**Proof.** Inequivalence has an NP witness: a world and a budget at most the complete horizon. Direct simulation is polynomial. For hardness, given CNF `phi`, build a forward controller that emits the sole result iff `phi` is true under the world, and compare it with a controller that never emits. The pair is equivalent iff `phi` is unsatisfiable. The graph has one read per literal occurrence plus polynomial control. Thus UNSAT reduces to equivalence. QED.

### Definition 6.2 (EXACT-BUDGET)

`EXACT-BUDGET` contains triples `(C_L,C_R,t)` for which `t` is the globally least separating budget. Equivalent pairs are not members for any `t`.

### Theorem 6.3 (EXACT-BUDGET is DP-complete)

`EXACT-BUDGET` is complete for `DP = {L1 intersect L2 : L1 in NP and L2 in coNP}`, even with one result label.

**Membership.** Let `H` be the complete acyclic horizon. If `t>H`, the first predicate is false because both traces have stabilized. Otherwise `t<=H`: “some world separates at `t`” is in NP, while the complement of “no world separates below `t`” guesses a world and `j<t`. Both simulations are polynomial, so their intersection is exactly `EXACT-BUDGET`.

**Hardness.** Reduce from the standard DP-complete language `SAT-UNSAT = {(phi,psi): phi is satisfiable and psi is unsatisfiable}`. Rename variables so the formulas use disjoint key blocks. Construct a fixed-length CNF evaluator that reads every literal occurrence, records in finite control whether each clause and the conjunction are satisfied, and then takes a true or false continuation. Fixed length is important: truth must not change the target budget.

Both controllers first evaluate `psi`. At the next instruction the left controller emits on a true evaluation and silently continues on false; the right controller silently continues in either case. Call this budget `e`. Both then evaluate `phi`. At the next instruction the left emits on true and silently terminates on false; the right always remains silent. Call this later budget `l`.

* If `psi` is satisfiable, a world separates at `e`, so `l` is not least.
* If `psi` is unsatisfiable and `phi` is satisfiable, no world separates before `l`, while a satisfying `phi` world separates at `l`.
* If both are unsatisfiable, the pair is equivalent.

Therefore `(C_L,C_R,l)` is in `EXACT-BUDGET` exactly when `(phi,psi)` is in `SAT-UNSAT`. The construction is polynomial and acyclic. QED.

The ranked negative certificate is thus proof evidence for a DP-complete statement, not merely a verbose encoding of an NP witness. Its size can still be exponential.

### Definition 6.4 (semantic key irrelevance)

At controller node `p`, key `x` is semantically irrelevant when for every pair of worlds that agree on all keys except possibly `x`, the complete residual observation traces from `p` are identical. This definition includes every budget and result.

### Theorem 6.5 (semantic key irrelevance is coNP-complete)

Deciding whether a designated key is semantically irrelevant at a designated node is coNP-complete, even with one result.

**Membership.** Relevance has an NP witness consisting of values for all other keys, the two values of the designated key, and a separating budget. Simulating both residual runs is polynomial. Hence irrelevance is in coNP.

**Hardness.** Given CNF `phi`, add a fresh key `x`. The controller first reads `x`. Its zero branch halts. Its one branch evaluates `phi` and emits iff `phi` is true. If `phi` is satisfiable, choose a satisfying assignment to the other keys: changing `x` changes the trace, so `x` is relevant. If `phi` is unsatisfiable, neither branch can emit under any assignment, so `x` is irrelevant. Thus UNSAT reduces to irrelevance. QED.

The syntactic future-read set is a sound overapproximation: a key absent from it cannot be read and cannot affect the residual trace. The theorem shows why replacing that inexpensive analysis with an exact maximal forgetting analysis is not expected to be polynomial unless `P=NP`. The finite census checks soundness on 1,584 nodes and finds strict overapproximation on 558 of them; it is validation, not the general proof.

## 7. Explicit-certificate lower bounds

The following lower bound concerns the article's explicit state-record certificate grammar. It is not a lower bound for symbolic algorithms, proof assistants, BDDs, or formats allowed to quantify over valuations.

For `k=2^d`, the executable selector pair uses two result labels. The left controller reads data keys `x_0,...,x_{k-1}` in increasing order; the right reads them in decreasing order. Both outcomes of each data read have the same control successor. Both controllers then read `d` selector keys, re-read the selected `x_i`, and halt on zero. In the equal pair both emit `r0` on one. In the mutation, the right emits `r1` instead.

Immediately after both data prefixes, every `x_i` remains live because a selector continuation may re-read it.

### Lemma 7.1 (pairwise distinct residuals)

The `2^k` exposed data valuations induce pairwise inequivalent conditioned residual observations.

**Proof.** Distinct valuations differ at some index `i`. Choose selector bits encoding `i`. The residuals then re-read different stored values and exactly one emits. QED.

### Theorem 7.2 (positive explicit-certificate lower bound)

Any accepted positive closed-safe-set certificate for the reverse-order equal-result pair contains at least `2^k` records at the paired selector controls after both data prefixes.

**Proof.** For every valuation `a in {0,1}^k`, choose one common world with data restriction `a`. The two data prefixes have the same length and reach the paired selector controls after `k` ticks. Every data key is live there, so the reduced memory is exactly `a`. The exact-path theorem makes all these states reachable. Distinct valuations are distinct concrete records, and root inclusion plus universal closure requires every reachable state. QED.

### Theorem 7.3 (negative safe-prefix lower bound)

For the reverse-order `r0`-to-`r1` mutation, the least separating budget is `k+log2(k)+2`, and every accepted ranked safe-prefix certificate contains at least `2^k` records at the post-data paired controls.

**Proof.** The `k` data reads, `log2(k)` selector reads, and selected re-read emit nothing, so no earlier budget separates. If the selected data bit is one, the next instruction emits `r0` on the left and `r1` on the right. Hence that budget is globally least. Every post-data valuation is reachable after `k` ticks, below the least budget, so Lemma 4.2 forces every such state into an accepted safe prefix with rank at most `k`. Accepted ranks need not equal reachable depths. QED.

For the measured sizes, all data keys are first exposed after `k/2` synchronized ticks because the two prefixes read disjoint keys in opposite directions. The finite check therefore records bottleneck ranks 1, 2, and 4 for `k=2,4,8`, while also checking the exact post-data controls at rank `k`. It verifies the read orders, exact data-key set, all `2^k` assignments, producer/oracle budget, strict JSON write/read round trip, and checker acceptance. These results explain the explicit producer's state cap and motivate symbolic certificate formats as future work. They do not contradict the succinct NP witness for inequivalence, because globally least separation adds a universal prefix claim.

## 8. Executable validation boundary

The artifact contains several deliberately separate paths:

1. the certificate producer and reduced product;
2. the strict certificate checker, which imports neither producer nor oracle transitions;
3. an exhaustive complete-world oracle for at most sixteen keys; and
4. a direct source interpreter compared with the source compiler; and
5. an independent path-set reconciler that imports none of the producer, checker, model, oracle, or workflow implementations.

For the two complete controller domains, the path reconciler independently enumerates the controller grammar, recomputes future-read masks, constructs reduced reachable state sets, and separately projects every concrete common-world run. It checks exact equality at every depth for 131,904 ordered pairs: 657,216 depth-indexed set equalities comprising 890,465 state occurrences on each side, with no mismatch. This is finite corroboration of the path theorem, not a mechanized proof.

The recorded Unix campaign includes 139,648 producer/oracle comparisons, 12,384 direct-interpreter/compiler trace comparisons, 8,256 terminal-denotation comparisons, 64 exact-budget reduction instances, 8 semantic-key reduction instances, a 1,584-node liveness census, 6 selector-certificate family instances, and the original 27 unit methods. Every recorded comparison agrees; campaign certificates are checked in memory, while pilot and selector construction fixtures also exercise serialization. Malformed records and four deliberately wrong relational semantics are rejected or distinguished as specified.

The current suite has 30 methods: three additions check shared-expression interning, an admitted 1,102-node expression, and negative ranks strictly below reachable depth. A Windows finite rerun passed those 30 methods and repeated the same finite semantic domains without disagreement. It called the reviewed generator functions without their Unix resource import; it did not execute the Unix reproduction wrappers or reproduce their resource measurements. Historical records remain unchanged until a new Unix full run regenerates them.

These finite results support implementation fidelity only. General validity comes from the arguments above; neither the proofs nor the implementation have been independently authored or mechanically verified.
